Dein Word-Führerschein 📝

7 Teile, einer pro Lektion. Mach zuerst Word auf und lass es offen: Dort probierst du alles aus. Fehler sind okay.

👆 Tipp das Wort an!

Markiert und gestaltet: fett, grösser, Farbe, Textmarker. Das lernst du in Teil 1.

💾 Dein Fortschritt bleibt auf diesem Gerät gespeichert. Niemand ausser dir sieht ihn.

💻 Word offen? Probier dort aus, wenn du unsicher bist.
📖 So geht’s: Schrift
  • Immer die Word-App: Datei im Explorer mit Doppelklick öffnen. Ist Word im Browser (Internet-Programm, z.B. Edge) aufgegangen (oben die Adresszeile)? Oben rechts «Bearbeitung» ▾ → «In Desktop-App öffnen». Nur die App hat alle Knöpfe.
  • Zuerst markieren, dann ändern. Ein Wort: Doppelklick. Ein Satz: Maus drücken und ziehen. Alles: Ctrl + A.
  • Schriftart: Reiter Start, Feld mit dem Namen der Schrift (z.B. «Arial») → Pfeil ▾ → andere Schrift wählen.
  • Schriftgrösse: Feld mit der Zahl (z.B. 12) → grössere Zahl = grössere Schrift. Man kann auch eine Zahl hineinschreiben und Enter drücken.
  • F = fett · K = kursiv (schräg) · U = unterstrichen.
  • A mit Farbstrich = Schriftfarbe (die Buchstaben). ab mit gelbem Strich = Textmarker (der Hintergrund, wie ein Leuchtstift).
  • Hoppla? Ctrl + Z macht den letzten Schritt rückgängig. Ctrl + S speichert.
💻 Word offen? Probier dort aus, wenn du unsicher bist.
📖 So geht’s: Absatz
  • Ausrichten: Start → Gruppe Absatz: linksbündig (normal), zentriert (Mitte, gut für Titel), rechtsbündig, Blocksatz (links und rechts gerade, wie in der Zeitung).
  • Zeilenabstand = Platz zwischen den Zeilen. Text markieren → Start → Knopf «Zeilen- und Absatzabstand» (Linien mit Pfeilen ↕) → z.B. 1,5.
  • Aufzählung (Punkte •): Reihenfolge egal, z.B. Zutaten. Nummerierung (1. 2. 3.): Reihenfolge wichtig, z.B. Schritte. Zeilen markieren → Start → Knopf.
  • Format übertragen (Pinsel, Start ganz links): in das schöne Wort klicken → Pinsel → über das andere Wort fahren. Doppelklick auf den Pinsel: für mehrere Stellen.
💻 Word offen? Probier dort aus, wenn du unsicher bist.
📖 So geht’s: Überschriften und Tabulator
  • Formatvorlagen (Start → Formatvorlagen): Titel = Name der ganzen Arbeit, Überschrift 1 = Kapitel, Überschrift 2 = Teil im Kapitel. In die Zeile klicken, dann die Vorlage wählen.
  • Warum? Word erkennt echte Überschriften: Sie stehen im Navigationsbereich (Ansicht → Navigationsbereich) und später im Inhaltsverzeichnis. Wichtig für Projektarbeiten.
  • Tabulator: Die Tab-Taste ⇥ (links neben Q) springt weiter. So stehen Zahlen genau untereinander. Nie viele Leerschläge machen!
  • ¶ (Alle anzeigen): zeigt versteckte Zeichen: · = Leerschlag, → = Tab, ¶ = Enter. Gedruckt werden sie nie.
💻 Word offen? Probier dort aus, wenn du unsicher bist.
📖 So geht’s: Bearbeiten und Prüfen
  • Suchen: Ctrl + F → Wort eintippen. Links siehst du jede Stelle.
  • Ersetzen: Ctrl + H (oder Start → Ersetzen) → «Suchen nach» → «Ersetzen durch» → Alle ersetzen.
  • Verschieben: markieren → Ctrl + X (ausschneiden) → hinklicken → Ctrl + V. Kopieren: Ctrl + C statt Ctrl + X, dann gibt es es zweimal.
  • Rote Wellenlinie: Word kennt das Wort nicht, vielleicht ein Fehler. Rechtsklick auf das Wort → Vorschlag wählen. Oder Überprüfen → Editor (F7). Du entscheidest: Nicht jeder Vorschlag stimmt.
  • Fast alles rot? Dann ist die Sprache falsch. Ctrl + A → Überprüfen → Sprache → «Sprache für die Korrekturhilfen festlegen» → Deutsch (Schweiz) → OK. Dann prüft Word mit «ss» statt «ß».
  • Wörter zählen: unten links in der Leiste (z.B. «287 Wörter») oder Überprüfen → Wörter zählen.
💻 Word offen? Probier dort aus, wenn du unsicher bist.
📖 So geht’s: Bild
  • Bild einfügen: Einfügen → Bilder → Dieses Gerät, Stockbilder oder Onlinebilder.
  • Grösse: Bild anklicken, an einer Ecke ziehen (nicht an der Seite, sonst wird es verzogen).
  • Wie fliesst der Text? Bild anklicken → Symbol Layoutoptionen daneben (oder Bildformat → Textumbruch):
  • Mit Text in Zeile: wie ein grosser Buchstabe in der Zeile (so kommt es neu herein, lässt sich schlecht schieben). Quadratisch: Der Text fliesst herum. Hinter den Text: wie ein Hintergrund. Vor den Text: liegt obenauf und lässt sich frei verschieben.
💻 Word offen? Probier dort aus, wenn du unsicher bist.
📖 So geht’s: Tabelle
  • Tabelle machen: Einfügen → Tabelle → Kästchen färben (z.B. 3 × 4) → klicken. Spalten stehen senkrecht, Zeilen liegen waagrecht.
  • Schreiben: Mit der Tab-Taste in die nächste Zelle. In der letzten Zelle macht Tab eine neue Zeile.
  • Zeile oder Spalte dazu: Rechtsklick in eine Zelle → Einfügen → Zeilen oberhalb / unterhalb, Spalten links / rechts.
  • Breite: die Linie zwischen zwei Spalten mit der Maus ziehen.
  • Farbe: Zellen markieren → Reiter Tabellenentwurf → Schattierung. (Der Reiter erscheint nur, wenn du in der Tabelle bist.)
💻 Word offen? Probier dort aus, wenn du unsicher bist.
📖 So geht’s: Seite und Abgabe
  • Hochformat / Querformat: Layout → Ausrichtung. Papier (A4 = Schulblatt, A3 = doppelt so gross): Layout → Format.
  • Seitenränder = der leere Platz aussen herum: Layout → Seitenränder → Schmal, Normal, Breit.
  • Neue Seite: Ctrl + Enter (Seitenumbruch). Nie viele Male Enter: Sonst verrutscht alles, wenn du oben etwas änderst.
  • Kopfzeile (oben) und Fusszeile (unten) stehen auf jeder Seite: Einfügen → Kopfzeile / Fusszeile. Seitenzahl: Einfügen → Seitenzahl → Seitenende. Zurück in den Text: Doppelklick in den Text oder Esc.
  • Vorschau und Drucken: Ctrl + P. Rechts ist die Vorschau: Erst prüfen, dann drucken.
  • Als PDF speichern: Datei → Speichern unter (oder «Kopie speichern») → Ordner → Dateityp PDF → Speichern. Umbenennen in «.pdf» macht kein PDF!
