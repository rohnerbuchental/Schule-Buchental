Dein Word-Führerschein 📝

5 Teile, einer pro Lektion. Ab Lektion 2 beginnt jede mit Aufwärmen: Da übst du alles von vorher nochmals. Denn einmal machen heisst noch nicht können. Fehler sind okay: Die Aufgabe kommt einfach später nochmals.

👆 Tipp das Wort an!

Markiert und gestaltet: fett, grösser, Farbe, Textmarker. Das lernst du in Teil 1.

💾 Dein Fortschritt bleibt auf diesem Gerät gespeichert. Niemand ausser dir sieht ihn.

📖 So geht’s: Schrift
  • Zuerst markieren, dann ändern. Ein Wort: Doppelklick. Ein Satz: Maus drücken und ziehen. Alles: Ctrl + A.
  • Schriftart: Reiter Start, Feld mit dem Namen der Schrift (z.B. «Arial») → Pfeil ▾ → andere Schrift wählen.
  • Schriftgrösse: Feld mit der Zahl (z.B. 12) → grössere Zahl = grössere Schrift. Man kann auch eine Zahl hineinschreiben und Enter drücken.
  • F = fett · K = kursiv (schräg) · U = unterstrichen.
  • A mit Farbstrich = Schriftfarbe (die Buchstaben). ab mit gelbem Strich = Textmarker (der Hintergrund, wie ein Leuchtstift).
  • Hoppla? Ctrl + Z macht den letzten Schritt rückgängig. Ctrl + S speichert.
📖 So geht’s: Absatz und Überschriften
  • Zeilenabstand = Platz zwischen den Zeilen. Text markieren → Start → Knopf «Zeilen- und Absatzabstand» (Linien mit Pfeilen ↕) → z.B. 1,5.
  • Überschriften: In die Zeile klicken → Start → Formatvorlagen → Überschrift 1 (Kapitel) oder Überschrift 2 (Teil im Kapitel).
  • Warum? Word erkennt echte Überschriften: Sie stehen im Navigationsbereich (Ansicht → Navigationsbereich) und später im Inhaltsverzeichnis (Referenzen → Inhaltsverzeichnis). Wichtig für Projektarbeiten.
  • Tabulator: Die Tab-Taste ⇥ (links neben Q) springt weiter. So stehen Zahlen genau untereinander. Nie viele Leerschläge machen!
  • Zu weit gesprungen? Mit der Rücktaste ⌫ einen Tab löschen.
📖 So geht’s: Bild und Tabelle
  • Bild einfügen: Einfügen → Bilder → Dieses Gerät, Stockbilder oder Onlinebilder.
  • Grösse: Bild anklicken, an einer Ecke ziehen (nicht an der Seite, sonst wird es verzogen).
  • Wie fliesst der Text? Bild anklicken → Symbol Layoutoptionen daneben (oder Bildformat → Textumbruch):
  • Mit Text in Zeile: Das Bild steht wie ein grosser Buchstabe in der Zeile (so kommt es neu herein). Quadratisch: Der Text fliesst um das Bild herum. Hinter den Text: Das Bild ist wie ein Hintergrund. Vor den Text: Das Bild liegt über dem Text und verdeckt ihn.
  • Tabelle: Einfügen → Tabelle → Kästchen färben (z.B. 3 × 4) → klicken. Spalten stehen senkrecht, Zeilen liegen waagrecht.
  • In der Tabelle springst du mit der Tab-Taste in die nächste Zelle. In der letzten Zelle macht Tab eine neue Zeile.
📖 So geht’s: Seite und Prüfen
  • Hochformat / Querformat: Layout → Ausrichtung. Hochformat = höher als breit. Querformat = breiter als hoch.
  • Rote Wellenlinie: Word kennt das Wort nicht, vielleicht ein Fehler. Rechtsklick auf das Wort → Vorschlag wählen. Oder Überprüfen → Editor (F7). Du entscheidest: Nicht jeder Vorschlag stimmt.
  • Fast alles rot? Dann ist die Sprache falsch. Ctrl + A → Überprüfen → Sprache → «Sprache für die Korrekturhilfen festlegen» → Deutsch (Schweiz) → OK. Dann prüft Word mit «ss» statt «ß».
  • Wörter zählen: unten links in der Leiste (z.B. «287 Wörter») oder Überprüfen → Wörter zählen.
📖 So geht’s: Papier, Drucken, PDF
  • A4 = normales Schulblatt, 21 × 29,7 cm. A3 = doppelt so gross (zwei A4 nebeneinander), gut für Plakate. A5 = halb so gross wie A4.
  • Papierformat einstellen: Layout → Format. (Layout → Ausrichtung ist Hoch- oder Querformat.)
  • Achtung: Ist das Dokument A3, aber im Drucker nur A4-Papier, wird es verkleinert oder abgeschnitten.
  • Drucken: Ctrl + P (oder Datei → Drucken). Rechts ist die Vorschau: Erst prüfen, dann drucken. Hier wählst du auch Drucker, Anzahl Kopien und Papier.
  • Als PDF speichern: Datei → Speichern unter (oder «Kopie speichern») → Ordner → Dateityp PDF → Speichern. Oder Datei → Exportieren → PDF/XPS-Dokument erstellen. Umbenennen in «.pdf» macht kein PDF!
