Fit am Computer 💻

3 Teile, einer pro Lektion. Jeder Teil hat 3 Stufen: erkennen, ergänzen, am Laptop machen. Fehler sind okay: Die Aufgabe kommt einfach später nochmals.

👆 Tipp die Wolke an!

Gespeichert in OneDrive: braucht kaum Platz auf dem Laptop und ist auch in Teams und auf dem Handy da.

💾 Dein Fortschritt bleibt auf diesem Gerät gespeichert. Niemand ausser dir sieht ihn.

📖 So geht’s: Dateien und OneDrive
  • OneDrive ist dein Speicher in der Cloud (Office-Konto, Zeichen: blaue Wolke ☁). Dein Laptop hat wenig Platz: Schularbeiten immer in OneDrive speichern. Du findest sie auch in Teams, auf office.com und auf dem Handy.
  • Datei-Explorer: gelber Ordner unten in der Leiste (oder Windows-Taste ⊞ + E).
  • Pfad lesen: «OneDrive › Schule › Informatik» heisst: Der Ordner Informatik liegt im Ordner Schule, und der liegt in OneDrive.
  • Ordner machen: Explorer → links «OneDrive» → oben «+ Neu» → «Ordner» → Namen schreiben → Enter.
  • Speichern unter: Datei → Speichern unter → Ordner wählen → Namen schreiben → Speichern. Nur «Speichern» behält Namen und Ort.
  • Guter Name: Fach und Thema, z.B. «Informatik_Steckbrief». Nicht «Dokument1».
  • Umbenennen: Datei anklicken → F2 → neuer Name → Enter. Die Endung (.docx) stehen lassen.
  • Verschieben: Datei anklicken → Ctrl + X (ausschneiden) → anderen Ordner öffnen → Ctrl + V (einfügen). Mit Ctrl + C (kopieren) hast du die Datei zweimal.
  • Endungen: .docx = Word · .pdf = PDF · .jpg / .png = Bild · .xlsx = Excel.
📖 So geht’s: Download, Screenshot, Teams
  • Herunterladen (Download): Die Datei landet im Ordner Downloads (Explorer → links «Downloads»).
  • Aufräumen: Wichtiges von Downloads nach OneDrive › Schule verschieben (Ctrl + X, Ctrl + V). Altes in Downloads löschen: So bleibt Platz auf dem Laptop.
  • Screenshot: Windows + Shift + S → mit der Maus ein Rechteck aufziehen. Das Bild ist jetzt in der Zwischenablage → ins Dokument klicken → Ctrl + V.
  • Wichtige Tasten: Ctrl + C kopieren · Ctrl + V einfügen · Ctrl + X ausschneiden · Ctrl + Z rückgängig · Ctrl + S speichern.
  • In Teams abgeben: Teams → «Aufgaben» → Aufgabe anklicken → «+ Arbeit hinzufügen» → Datei aus OneDrive wählen → «Abgeben». Erst nach «Abgeben» sieht die Lehrperson deine Arbeit.
📖 So geht’s: Word
  • Zuerst markieren, dann ändern. Markieren: Maus drücken, gedrückt halten, über den Text ziehen.
  • Reiter «Start»: F = fett · K = kursiv (schräg) · U = unterstrichen · A = Schriftfarbe · Zahl = Schriftgrösse.
  • Bild einfügen: Reiter «Einfügen» → «Bilder». Grösse ändern: Bild anklicken und an einer Ecke ziehen.
  • Hoppla? Ctrl + Z macht den letzten Schritt rückgängig.
  • Als PDF speichern: Datei → Speichern unter (oder «Kopie speichern») → Ordner wählen → bei «Dateityp» PDF → Speichern. Umbenennen in «.pdf» macht kein PDF!
  • Warum PDF? Ein PDF sieht auf jedem Gerät gleich aus. Gut zum Abgeben.
