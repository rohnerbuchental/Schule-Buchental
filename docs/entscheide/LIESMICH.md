# Entscheide

Eine Datei pro Entscheid, Name `JJJJ-MM-TT-kurzer-name.md`. Ein Entscheid wird nie umgeschrieben: nur mit datiertem Nachtrag («## Nachtrag JJJJ-MM-TT») ergänzen oder durch einen neuen ersetzen (im neuen unter «Ersetzt» nennen, im alten einen Nachtrag mit Verweis). Was Claude selbst entscheidet, bekommt «von Claude festgelegt».

## Vorlage

```
# <Titel>

- Datum: JJJJ-MM-TT
- Entscheid: <ein bis drei Sätze>
- Entschieden von: Jonas / von Claude festgelegt
- Begründung:
- Folgen:
- Prüfpunkt:
- Ersetzt: <Datei oder nichts>
- Quelle: <Chat, Datei, Commit>
```
