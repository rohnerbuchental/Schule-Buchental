# Lehrplan (Kompetenzen Zyklus 3)

Auszüge aus dem Lehrplan Volksschule Kanton St.Gallen (Lehrplan 21), Stand August 2025.
Quelle und Urheberrecht: Bildungsdepartement Kanton St.Gallen, [sg.lehrplan.ch](https://sg.lehrplan.ch).

| Datei | Fach | Codes |
|---|---|---|
| `deutsch.md` | Deutsch | D.1–D.6 |
| `englisch.md` | Englisch (1. Fremdsprache) | FS1E.1–FS1E.6 |
| `medien-informatik.md` | Medien und Informatik | MI.1, MI.2 |
| `rzg.md` | Räume, Zeiten, Gesellschaften | RZG.1–RZG.8 |
| `bildnerisches-gestalten.md` | Bildnerisches Gestalten | BG.1–BG.3 |

## Lesen
- Jeder Punkt hat seinen vollen Code, z.B. `MI.2.2.h`. Suchen mit `grep -n "MI.2.2" lehrplan/medien-informatik.md`.
- **GA** = Grundanspruch (grau hinterlegt im Lehrplan): Das sollen alle erreichen.
- *(Zyklus 2)* = letzte Stufe vor der Oberstufe, zum Anknüpfen.
- Englisch: *(GER A2.2)* usw. = Niveau nach Europäischem Referenzrahmen.
- RZG: *Inhalte* = verbindliche Inhalte zu diesem Punkt.
